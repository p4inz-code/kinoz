# Roadmap

What's planned, in rough order. Nothing here is a promise or a date.

**Done recently** (see [CHANGELOG.md](CHANGELOG.md))
- Fast skimming, keep / reject / delete, watched marks, number-key jumps.
- Music library, saved playlists (`.m3u8`), Windows media overlay (now playing card).
- Updates that download in the background, ask "Restart now / Later", and install on the next launch if you pick Later.
- Safe mode after two abnormal exits; a self-drawn setup with a Doctor and full uninstall.

**Next**
- Verify the macOS and Linux builds on real machines and fix what breaks; add macOS Now Playing and Linux MPRIS.
- Album art in the Music lists and the media overlay.
- Gapless playback for albums.
- Play a web address (direct media links only).

**Then**
- HEIC / AVIF image support check and fixes.
- Lower memory use per window; shared thumbnail service across windows.
- Subtitle search and download (opt-in, off by default).
- Optional "install updates when I close kinoz" mode.

**Not planned**
- Accounts, cloud sync, telemetry, ads.
- Streaming-service integrations, casting, CD or DVD features.

Have an idea? [Open an issue](https://github.com/p4inz-code/kinoz/issues/new/choose).
