# Support

- **Bugs and ideas:** [open an issue](https://github.com/p4inz-code/kinoz/issues/new/choose). Include your OS, the kinoz version (Settings → About) and, if you can, `data/logs/app.log`.
- **Chat:** [Discord](https://discord.gg/8UKt8s5FbW)
- **Security problems:** see [SECURITY.md](SECURITY.md) — please report privately.
- **Something not working after an update?** Check [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md) first.

kinoz is made by one person, so replies can take a little while.
